### Gauss
*Код*: https://github.com/app-jar/haskell/blob/main/Gauss/app/Main.hs

Реализация метода Гаусса-Жордана для решения систем линенйных алгебраических уравнений
https://mathprofi.ru/metod_gaussa_dlya_chainikov.html

Метод содержит два этапа:
1. Прямой ход - приведение расширенной матрицы коэфициентов к верхнетреугольному виду методом умножения строк на скаляр и вычитания строк
2. Обратный ход - приведение матрицы к единичной путем тех же преобразований.
